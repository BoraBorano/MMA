## 4. 담당자 승인 대기 항목 (PRD 17.3 잔여, 코드로 해결 불가)

Iteration 1에서 이미 확정된 항목(공개 지역 범위, 경기도 매핑, 중복 시설, 감면 누락 처리, 검색 범위, 후속 기능 노출)은 모두 구현에 반영 완료. 아래는 여전히 조직 차원의 승인이 필요한 항목이다.

| 항목 | 현재 상태 | 승인 시 조치 |
|---|---|---|
| Gmarket Sans 폰트 라이선스 | 시스템 한글 산세리프 대체 적용 중 (`--font-sans` 토큰 1곳) | 라이선스 확정 시 토큰 값만 교체 — 코드 변경 범위 최소 |
| 경기도 행정구역 SVG 및 사용권 | 이번 개발 단계 제외 확정, 목록 단일 방식으로 구현 | 승인 SVG 확보 시 별도 후속 스프린트에서 지도 컴포넌트 추가(설계상 슬롯 유지) |
| 기관명·로고 사용 승인 | 로고 미사용(텍스트 서비스명만 사용) | 승인 시 ServiceHeader에 로고 추가 |
| 네이버 지도 연결 정책·최종 URL 형식 | `https://map.naver.com/p/search/{인코딩된 시설명+주소}` 형식으로 구현, 자동 테스트로 URL 생성 검증 완료 | 실기기 최종 동작 확인 필요(에뮬레이터 한계) |
| 데이터 갱신 담당자·승인자·주기 | README에 갱신 절차(스크립트 실행 방법)만 문서화 | 조직 내 담당자 지정 필요 — 코드 영향 없음 |
| 삼성 인터넷·Safari 실기기 확인 | Chromium 기반 자동화로 3뷰포트 검증 완료, 실제 삼성 인터넷·Safari 미검증 | 실기기 1대 이상 수동 확인 권장 |

## 5. 최종 판정

**조건부 배포 가능(Conditional Go)**

- 기능·데이터·접근성·반응형 요구사항은 테스트 245건(단위 116 + E2E 129)으로 전수 검증되어 **전부 통과**했다.
- 출시 차단 조건 14항 중 13항은 명확히 해당 없음(통과), 1항(자산 사용권)은 **조직 승인이 남아 있어 기술적으로는 배포 가능하나 PRD 규정상 담당자 승인 없이 최종 공개를 진행하지 않는다.**
- §4의 승인 대기 항목들은 모두 코드에 최소 영향으로 반영될 수 있도록 설계(토큰 분리, 지도 슬롯 유지)되어 있어, 승인이 완료되면 별도 리팩터링 없이 신속히 반영 가능하다.
