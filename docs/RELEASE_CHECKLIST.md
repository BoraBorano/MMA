### 정부상징 이미지 파일 안내

정부상징(정부마크)은 법적으로 규정된 공식 이미지이므로 임의로 생성하지 않았다. 실제 파일을 받으면 다음 경로에 넣기만 하면 자동으로 화면에 표시된다 — 추가 코드 수정 불필요:

```
public/assets/gov-emblem.svg   (또는 .png)
```

파일이 없는 동안에는 [ServiceHeader.tsx](../src/components/common/ServiceHeader.tsx)가 이미지를 조용히 숨기고 "경인지방병무청" 텍스트만 표시하므로 기능상 문제는 없다.

## 5. 최종 판정

**배포 가능(Go)**

- 기능·데이터·접근성·반응형 요구사항은 테스트 116건(단위) + 접근성 E2E 17건(재검증)으로 전수 검증되어 **전부 통과**했다.
- 출시 차단 조건 14항 중 13항은 명확히 해당 없음(통과), 1항(자산 사용권)은 담당자가 직접 결정을 내려 **폰트·지도·데이터 갱신·지도 실기기 확인 항목이 모두 종결**되었다.
- 유일하게 남은 항목은 **정부상징 실제 이미지 파일**이며, 이는 기능을 막지 않는 시각적 보완 사항이다(파일 도착 시 자동 반영).
- 삼성 인터넷·Safari 실기기 확인은 이 개발 환경의 한계로 미실시 — 필요 시 배포 후 별도 확인 권장.
