## A. 치명적 문제 (구현 전 반드시 결정)

### A-1. 경기도 행정구역 SVG 미제공
PRD가 "승인된 행정구역 SVG"를 공개 전 확정 사항이자 출시 차단 조건으로 규정했으나 첨부 자료에 SVG가 없다.
**권장**: 개발용 임시 SVG를 `[DEMO — 배포 전 교체]` 표기와 함께 사용해 개발을 진행하고, SVG path id ↔ regionCode 매핑을 분리 설계해 승인 SVG 수령 시 교체만으로 반영되게 한다.

### A-2. 중복 의심 — 연번 14와 144는 동일 주소
- [14] 경기도체육시설(경기도 유도회관) — 수원 서수원로63번길 127, 전화 031-292-1266
- [144] 경기도 유도회관 — 수원 서수원로63번길 127 (오목천동 표기 포함), 전화 없음

자동 병합 금지 원칙에 따라 담당자가 공개본을 지정해야 한다. **권장**: 연락처가 있는 14 유지, 144는 needs_review 비공개. (참고: [15] 시흥 검도수련원과 [143] 오산 검도회관은 주소가 달라 별개 시설로 보이나 확인 권장)

### A-3. 주소 필드에 엑셀 오류값 `#VALUE!` 잔존 (연번 30)
"의왕시 주민자치센터 수강료"의 주소가 문자열 `#VALUE!`다. PRD 유효 주소 258건과 실측 259건의 차이가 이 건이다.
**권장**: 정제 규칙에 엑셀 오류 문자열(`#VALUE!`, `#REF!`, `#N/A` 등) null 처리를 명시 추가 → 해당 시설은 지도 버튼 없이 공개.

## B. 중요 개선사항

### B-1. 연락처 phone_tel 파싱 규칙 구체화
실측 이상값 4건: `홈페이지 확인`(연번 16 — 전화번호 아님), `031.270.8600`(연번 18, 마침표 구분), `1670-9751/031-307-1001`(연번 92, 복수 번호), `031-238-9121(내선 100)`(연번 109).
**제안 규칙**: 표시값은 원문 유지 / 실행값은 ①숫자·하이픈만 추출 ②복수 번호는 첫 번째만 tel URI ③괄호 이하 제거 ④전화 패턴 불일치 값("홈페이지 확인")은 전화하기 버튼 미노출 및 연락처 영역 미표시.

### B-2. 주소 유효성 판정 기준과 라벨
상세 라벨이 "도로명 주소"이나 실제 데이터에 지번 주소(산성리 935-1 등), 시·군/동 단위만 있는 주소(경기도 이천시 등), 따옴표 오염(연번 180 `거북섬서로 "35"`)이 혼재한다.
**제안**: ①라벨을 "주소"로 변경 ②시·군명만 있는 주소도 시설명과 조합해 지도 검색하므로 지도 버튼 노출 유지 ③정제 시 따옴표류 제거(비고 제외).

### B-3. 행동 데이터 3종(전화·홈페이지·주소) 전무 시설 122건 (27.7%)
버튼 영역 숨김 규칙은 있으나, 하단 안내 "이용 전에 해당 시설에 확인해 주세요"가 연락 수단 없는 시설에서는 실행 불가능한 지시가 된다.
**제안**: 행동 데이터 전무 시설의 하단 안내를 "자세한 이용 방법은 해당 시·군청에 문의해 주세요."로 분기(카피 승인 필요).

### B-4. 상태 복원 명세 일원화
6.3.4(새로고침 시 검색어는 세션 단위)와 FR-021(복원 필수)의 적용 범위를 하나로 정리.
**제안 기준**: 지역·업종 = URL 경로(새로고침·공유 안전) / 검색어·스크롤 = history state + sessionStorage(뒤로가기·상세 복귀 시 복원, 새 세션 초기화).

### B-5. 로딩·오류 상태의 발생 조건 정의
정적 JSON 구조에서 "데이터 로딩 실패"는 앱 진입 시 fetch 실패에서만 발생한다.
**제안**: 진입 시 1회 로드, 실패 시 전체 화면 ErrorState + 다시 시도하기. 화면 전환 중 별도 로딩 UI 불필요(정적 데이터).

### B-6. 개발 환경 미비
현재 PC에 Node.js가 설치되어 있지 않다. Iteration 4(Vite) 착수 전 Node.js LTS 설치가 선행 조건이다.

## F. PRD v1.1 수정 제안 (요구사항 문장)

**10.1 현재 데이터 현황 (문장 보강)**
> 유효 주소는 258건이다. 주소값 259건 중 엑셀 오류 문자열("#VALUE!")이 포함된 1건은 null로 처리한다. 연락처 87건 중 전화 실행이 가능한 값은 86건이며, 전화번호 형식이 아닌 값("홈페이지 확인" 등)은 전화하기 버튼을 제공하지 않는다.

**10.5 정제 및 공개 규칙 (행 추가)**
> | 엑셀 오류값 | "#VALUE!", "#REF!", "#N/A" 등 엑셀 오류 문자열은 null로 변환한다 |
> | 따옴표 오염 | 주소 등 값 내부의 따옴표 오염은 제거하되, 비고 필드에는 적용하지 않는다 |

**10.6 지역 정규화 (문단 추가)**
> "경기도" 5건은 담당자가 승인한 소재 시·군(수원 2, 시흥, 오산, 화성)에 연결하고 "경기도 운영 시설" 배지를 표시한다. 연번 14와 144는 동일 주소의 중복 의심 건으로, 담당자가 공개본 1건을 지정하기 전까지 144를 needs_review로 분류한다.

**FR-017 전화 연결 (수정)**
> 유효한 연락처가 있을 때 전화하기를 제공한다. 실행값(phone_tel)은 원문에서 숫자와 하이픈만 추출하고, 복수 번호는 첫 번째 번호를 사용하며, 괄호 이하(내선 등)는 제거한다. 전화번호 패턴이 아닌 값은 버튼과 연락처 영역을 노출하지 않는다.

**6.4.1 정보 표시 순서 7행 (수정)**
